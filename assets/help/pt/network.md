# Rede e Wi-Fi

A rede é gerenciada em [Ajustes → Rede](settings:network). No alto há uma linha por conexão
(cabo, Wi-Fi e VPN); a Central de controle mostra a principal.

- **Cabo:** conecta sozinha por DHCP. Também dá para definir um **IP fixo** (endereço, gateway e
  DNS).
- **Wi-Fi:** escolha a rede e digite a senha. As redes salvas reconectam sozinhas, e “Esquecer”
  as apaga.
- **Estado:** endereço IP, gateway, DNS e tráfego de cada conexão.

A rede é do **sistema**, não da sua sessão: ela sobe quando o computador liga, antes de alguém
entrar, e continua igual quando você troca de usuário ou sai da sessão. Por isso a tela de login já
mostra o IP do computador.

Conectar a uma Wi-Fi não exige ser administrador; mudar a configuração de uma placa, sim. As senhas
das redes são guardadas pelo sistema e só o root as lê. Para VPN, veja [VPN](help:vpn).
