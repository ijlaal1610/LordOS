# Imprimir

- **Imprimir:** ❖P (ou Arquivo → Imprimir) no Editor, Notas, Visualizador de PDF e Fotos abre a
  caixa de diálogo do sistema: impressora, cópias, páginas, frente e verso, cor e tamanho do papel,
  com pré-visualização. Também dá para **salvar como PDF**.
- **Adicionar uma impressora:** [Ajustes → Impressoras e scanners](settings:printers). As da rede
  aparecem sozinhas; também dá para adicionar uma pelo endereço. É preciso ser administrador.
- **Fila:** ali mesmo aparecem os trabalhos pendentes, que podem ser cancelados.

Para digitalizar, veja [Scanner](help:scanner).
