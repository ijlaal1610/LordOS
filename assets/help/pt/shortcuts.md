# Atalhos de teclado

❖ é a tecla Super. Em quase todos os apps o Ctrl também funciona.

## Em todo o sistema

| Atalho | O que faz |
|---|---|
| ❖Espaço · Ctrl+Espaço | Spotlight: buscar apps, arquivos, ajustes e ajuda |
| ❖ sozinha · F4 | Launchpad |
| ❖⌥Espaço | Próximo layout de teclado ou método de entrada |
| ❖V · ❖⇧V | Área de transferência: o último · o histórico completo |
| ❖. | Emojis e símbolos |
| ❖⇧3 · Print Screen | Captura da tela inteira |
| ❖⇧4 | Captura de uma área (Espaço: de uma janela) |
| ❖⇧5 | Painel de Capturas e gravação da tela |
| ❖L · ❖Ctrl+Q | Bloquear a tela |
| Teclas multimídia | Tocar, pausar, próxima e anterior no Reprodutor |

## Nos apps

| Atalho | O que faz |
|---|---|
| ❖N · ❖T · ❖W | Nova janela · nova aba · fechar |
| ❖F · ❖G | Buscar · próximo resultado |
| ❖C · ❖X · ❖V | Copiar · recortar · colar |
| ❖Z · ❖⇧Z | Desfazer · refazer |
| ❖S · ❖P | Salvar · imprimir |

Cada app explica os seus no próprio artigo: [Arquivos](help:files), [Terminal](help:terminal),
[Editor de texto](help:editor) e [Notas](help:notes).
