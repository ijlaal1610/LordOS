# Instalar o LordOS

No sistema ao vivo (o pendrive ou o CD do LordOS), o assistente **Instalar o LordOS** copia o
sistema para o disco.

1. Idioma, região e fuso horário.
2. Teclado, com um campo para testar.
3. **Disco:** é apagado inteiro. Para continuar é preciso marcar “Entendo que o disco inteiro será
   apagado” e digitar o nome dele.
4. Seu usuário, a senha (duas vezes) e o nome do computador.
5. Resumo e **Instalar**: particiona, copia, configura e instala o carregador de boot (UEFI e BIOS).

No final, “Reiniciar” e tire o pendrive. O sistema instalado entra pela tela de login com o seu
usuário. Este app só existe no sistema ao vivo.
