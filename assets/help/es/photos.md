# Fotos

La fototeca de `~/Imágenes`, con miniaturas y un visor.

- **Ver:** zoom con + y − (o pellizcando), 0 encaja, 1 es tamaño real, ← → pasan de foto.
- **Girar:** R. **Pantalla completa:** F. **Presentación:** Espacio. **Imprimir:** ❖P.
- **Editar:** recorte, giro, brillo y contraste. Se guarda siempre **como copia**: el original no
  se toca.
- Abre PNG, JPEG, WebP, BMP, GIF animados, HEIC y AVIF.

Las imágenes se decodifican en un proceso aparte y encerrado: un archivo dañado no puede afectar
al escritorio.
