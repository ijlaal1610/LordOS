# Grabadora

Notas de voz con el micrófono.

- **Grabar** y **detener**; mientras graba se ve la forma de onda.
- La lista guarda todas las grabaciones: renombrarlas, escucharlas o **recortarlas**.
- **Exportar** a Opus, MP3 o WAV.

La primera vez pide el permiso de **micrófono**. El micrófono se elige en
[Ajustes → Sonido](settings:sound).
