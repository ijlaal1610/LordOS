# Red y Wi-Fi

La red se maneja en [Ajustes → Red](settings:network). Arriba hay una fila por conexión (cable,
Wi-Fi y VPN); el Centro de control muestra la principal.

- **Cable:** se conecta solo por DHCP. También se puede poner una **IP fija** (dirección,
  puerta de enlace y DNS).
- **Wi-Fi:** elegí la red y escribí la contraseña. Las redes guardadas se reconectan solas, y
  «Olvidar» las borra.
- **Estado:** dirección IP, puerta de enlace, DNS y tráfico de cada conexión.

La red es del **sistema**, no de tu sesión: se levanta al arrancar el equipo, antes de que alguien
entre, y sigue igual cuando cambiás de usuario o cerrás la sesión. Por eso la pantalla de ingreso
ya muestra la IP del equipo.

Conectarse a una Wi-Fi no necesita ser administrador; cambiar la configuración de una placa sí.
Las contraseñas de las redes se guardan en el sistema y solo las lee root. Para las VPN, ver
[VPN](help:vpn).
