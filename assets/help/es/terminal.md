# Terminal

Una terminal nativa con pestañas, paneles, perfiles y búsqueda.

## Atajos principales

| Atajo | Qué hace |
|---|---|
| ❖T · ❖N | Pestaña nueva · ventana nueva |
| ❖D · ❖⇧D | Dividir a la derecha · abajo |
| ❖] · ❖[ | Panel siguiente · anterior |
| ❖1 … ❖9 | Ir a una pestaña |
| ❖W · ❖Z | Cerrar panel · deshacer el cierre (5 s) |
| ❖F · ❖G | Buscar · siguiente |
| ❖C · ❖V · ❖⇧H | Copiar · pegar · historial de pegado |
| ❖= · ❖- · ❖0 | Agrandar · achicar · tamaño real |
| ❖K | Limpiar |
| ❖, | Preferencias y perfiles |
| F12 | Ventana desplegable desde arriba |

## Más

- **Modo copia con el teclado** (❖⇧C), **Instant Replay** para ver lo que pasó (❖⌥B) y marcas de
  tiempo por línea (❖⇧E).
- **Avisar cuando termine el comando** (❖⌥A) y transmitir lo que escribís a todos los paneles (❖⌥I).
- **Perfiles:** colores, fuente, transparencia y comando; se pueden importar de otros emuladores de terminal.
- **tmux -CC:** las ventanas y paneles de tmux se ven como pestañas y paneles nativos.
- Las sesiones **sobreviven a un reinicio** del escritorio: al volver, siguen ahí.

La Terminal abre solo tu shell de siempre, con tus permisos de usuario.
