# Editor de texto

Un editor de código al estilo de TextMate: proyecto, pestañas, varios cursores, buscar y
reemplazar y resaltado de sintaxis.

- **Proyecto:** ❖⇧O abre una carpeta; ❖\ muestra u oculta el árbol; ❖T abre un archivo del
  proyecto escribiendo algunas de sus letras en orden («wjs» → windows.js).
- **Varios cursores:** ⌥clic agrega uno; ❖D selecciona la palabra y después la próxima aparición.
  Esc vuelve a un solo cursor.
- **Buscar y reemplazar** (❖F): texto o expresión regular, con o sin mayúsculas, «2 de 7».
- **Ir a línea:** ❖L (`120` o `120:8`).
- **Comentar:** ❖/ según el lenguaje. **Duplicar línea:** ❖⇧D. **Sangrar:** ❖] y ❖[.
- **Archivos:** ❖N nuevo, ❖O abrir, ❖S guardar, ❖⇧S guardar como, ❖W cerrar, ❖P imprimir.

Los archivos de texto y código de [Archivos](help:files) y de Buscar se abren acá. Funciona con
los métodos de entrada de japonés, chino y coreano.
