# Escáner

Escanea con los escáneres de la red que no necesitan controlador (eSCL, también llamado AirScan;
la mayoría de las multifunción modernas).

1. Elegí el escáner: aparecen solos los de tu red.
2. **Vista previa** y, si querés, arrastrá para elegir el área.
3. Elegí color o grises, la resolución y, si tiene, el alimentador de hojas.
4. **Escanear** y guardar como **PDF**, **PNG** o **JPEG** en Documentos o Imágenes.

Las impresoras se agregan en [Ajustes → Impresoras](settings:printers) (ver [Imprimir](help:printing)).
