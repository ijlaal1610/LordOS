# Text Editor

A code editor in the style of TextMate: project, tabs, multiple cursors, find and replace and
syntax highlighting.

- **Project:** ❖⇧O opens a folder; ❖\ shows or hides the tree; ❖T opens a project file by typing
  some of its letters in order (“wjs” → windows.js).
- **Multiple cursors:** ⌥click adds one; ❖D selects the word and then the next occurrence. Esc goes
  back to a single cursor.
- **Find and replace** (❖F): text or regular expression, case sensitive or not, “2 of 7”.
- **Go to line:** ❖L (`120` or `120:8`).
- **Comment:** ❖/ depending on the language. **Duplicate line:** ❖⇧D. **Indent:** ❖] and ❖[.
- **Files:** ❖N new, ❖O open, ❖S save, ❖⇧S save as, ❖W close, ❖P print.

Text and code files from [Files](help:files) and Spotlight open here. It works with the Japanese,
Chinese and Korean input methods.
