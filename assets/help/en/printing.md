# Printing

- **Print:** ❖P (or File → Print) in Editor, Notes, PDF Viewer and Photos opens the system dialog:
  printer, copies, pages, two-sided, color and paper size, with a preview. You can also **save as
  PDF**.
- **Add a printer:** [Settings → Printers & Scanners](settings:printers). Network printers show up
  by themselves; you can also add one by its address. It requires an administrator.
- **Queue:** in the same place you see pending jobs and cancel them.

To scan, see [Scanner](help:scanner).
