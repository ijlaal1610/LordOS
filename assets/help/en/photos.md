# Photos

The photo library of `~/Pictures`, with thumbnails and a viewer.

- **View:** zoom with + and − (or pinch), 0 fits, 1 is actual size, ← → move between photos.
- **Rotate:** R. **Full screen:** F. **Slideshow:** Space. **Print:** ❖P.
- **Edit:** crop, rotate, brightness and contrast. It always saves **as a copy**: the original is
  never touched.
- It opens PNG, JPEG, WebP, BMP, animated GIF, HEIC and AVIF.

Images are decoded in a separate, sandboxed process: a damaged file cannot affect the desktop.
