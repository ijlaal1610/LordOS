# Keyboard shortcuts

❖ is the Super key. In almost every app Ctrl works too.

## System-wide

| Shortcut | What it does |
|---|---|
| ❖Space · Ctrl+Space | Search: find apps, files, settings and help |
| ❖ alone · F4 | Apps (the app launcher) |
| ❖⌥Space | Next keyboard layout or input method |
| ❖V · ❖⇧V | Clipboard: latest items · full history |
| ❖. | Emoji and symbols |
| ❖⇧3 · Print Screen | Screenshot of the whole screen |
| ❖⇧4 | Screenshot of an area (Space: of a window) |
| ❖⇧5 | Screenshots panel and screen recording |
| ❖L · ❖Ctrl+Q | Lock the screen |
| Media keys | Play, pause, next and previous in Player |

## In apps

| Shortcut | What it does |
|---|---|
| ❖N · ❖T · ❖W | New window · new tab · close |
| ❖F · ❖G | Find · next result |
| ❖C · ❖X · ❖V | Copy · cut · paste |
| ❖Z · ❖⇧Z | Undo · redo |
| ❖S · ❖P | Save · print |

Each app explains its own in its article: [Files](help:files), [Terminal](help:terminal),
[Text Editor](help:editor) and [Notes](help:notes).
